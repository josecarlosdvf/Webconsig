# Webconsig CRM System

**Modern CRM System** built with Flask and PostgreSQL, using the Volt Dashboard design with Bootstrap 5.
The system is designed to be secure, fast, and scalable for managing customer relationships.

<br />

## Features

- **Modern Technology Stack**: Flask 3.1, SQLAlchemy 2.0, PostgreSQL
- **Security First**: Latest security patches and best practices
- **Clean Architecture**: Blueprint Pattern for easy extension
- **Bootstrap 5**: Modern, responsive UI with Volt Dashboard design
- **Authentication**: Session-based auth with optional OAuth (GitHub, Google)
- **Database**: PostgreSQL with SQLAlchemy ORM
- **Async Tasks**: Celery with Redis for background processing
- **Docker Ready**: Complete Docker and docker-compose setup
- **Production Ready**: Configured for deployment with Gunicorn and Nginx

<br />

## Technology Stack

- **Backend**: Flask 3.1.0, Python 3.12+
- **Database**: PostgreSQL (recommended), SQLite (development fallback)
- **ORM**: SQLAlchemy 2.0.38
- **Auth**: Flask-Login, Flask-Dance (OAuth)
- **Frontend**: Bootstrap 5, Vanilla JavaScript, Vite
- **Task Queue**: Celery 5.4.0 with Redis
- **Deployment**: Docker, Gunicorn, Nginx
